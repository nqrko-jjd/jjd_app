# Photos du site vitrine

Déposer les images ici avec **exactement ces noms** (`.jpg`).
Tant qu'un fichier manque, un emplacement vert soigné s'affiche à la place.

Format conseillé : JPEG, largeur ~1600 px, < 400 Ko (compresser).
Cadrage : les images sont recadrées en « cover », prévoir de la marge.
